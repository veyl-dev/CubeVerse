# CubeVerse project status

Updated: 2026-11-02. Status reflects repository source, not a device/store certification.

## Implemented in this repository

- [x] Native Unity/C# project scaffold for Android; portrait launch scene is generated by the Unity editor setup script.
- [x] 2×2, 3×3, 4×4 and 5×5 integer cubie state with sticker colors/normals, actual layer transformations, solved-state detection, legal move sequences, move notation, scramble generation, reset/restart, undo and redo.
- [x] Runtime-built 3D cubie/sticker rendering and quarter-turn animation with final discrete-state snap; no fake sticker-only turns.
- [x] Mouse/touch drag layer turns and cube view orbit; Classic, Speedcubing (15-second inspection), and Practice session selections.
- [x] Solve timer, move counter, local best single, rolling history and trimmed average-of-five; local persistence through Unity PlayerPrefs.
- [x] Independent local sound/haptics toggles, procedural turn feedback, responsive portrait-oriented runtime HUD.
- [x] Unity Test Framework test sources cover sizes 2–5, face/inverse and four-turn invariants, scrambles, notation and invalid algorithms.

## Not yet verified here

- [ ] Google Play target API and policy compliance: the editor setup selects the latest installed SDK automatically; verify the actual build target against Google Play requirements before release.

Do not treat any item marked not verified or not implemented as finished. The core engine/test source is committed separately from claims about a built and certified Android release.
